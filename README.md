# mama-nook · 宝妈树洞

给妈妈的情绪树洞。累、委屈、内疚，或有些说不清的不舒服，都可以来聊聊。

## 它能做什么

- **听你说**：接住情绪，不评判，也不急着给建议。
- **陪你理一理**：帮你说清感受，看看压力来自哪里。
- **帮你开口**：面对伴侣、长辈或同事，想一句你说得出口的话。

适合聊带娃的疲惫、家庭分工、代际关系和职场压力。回复尽量简短，需要时只给一个小动作。它关注妈妈自己的状态，不提供育儿训练方案，也不替代心理咨询或医疗服务。

## 怎么安装

需要一个支持 `SKILL.md` 技能的 AI 工具。

1. 在本仓库点击 **Code → Download ZIP**，下载并解压。
2. 将解压后的文件夹改名为 `mama-nook`，放进所用工具的技能目录；具体目录以该工具的说明为准。
3. 保留下面的结构，然后重新打开会话或刷新技能列表。

```text
mama-nook/
├── SKILL.md
└── references/
    ├── authors.md
    ├── scripts.md
    └── style.md
```

仓库目前为私有，下载需要有访问权限。无需单独安装依赖或配置 API Key，使用你已有的 AI 工具和模型即可。

## 怎么使用

在聊天中直接点名 `mama-nook` 或「宝妈树洞」，再说出此刻想说的话：

> 用 mama-nook。我今天带娃好累，先别给建议，听我说说。

> 用宝妈树洞。我明明一直在忙，却总觉得自己做得不够好，陪我理一理。

> 用 mama-nook。我想让老公接手晚上的哄睡，但不知道怎么开口。

不用组织好语言，也不用一次讲清楚。想倾诉、想理思路、想找一句话，随时可以切换。

## 关于隐私

技能默认不主动写入记忆，也不把倾诉内容用于联网搜索。只有你明确要求「记住」时，才按规则保存到本地 `~/.mama-nook/memory.md`；可以说「忘掉这件事」或「全部忘掉」。记忆功能需要工具支持本地文件读写。

聊天记录是否保存、内容是否经过云端模型，取决于你使用的 AI 工具及其隐私设置。
